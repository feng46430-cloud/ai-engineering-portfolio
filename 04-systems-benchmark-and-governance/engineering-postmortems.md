# 精选 5 大通用工程根因排障案例复盘（Engineering Postmortems）

> [!NOTE]
> **合规与净室声明（Clean-Room Disclaimer）**：本文收录的 Case 2–5 均源自作者个人开源与独立自研项目；Case 1 为通用网络/UDP 协议排障模式抽象（Clean-room abstraction），不包含任何过往或现任职企业的内部业务数据、厂商名称、私有代码或受 NDA 保护资产。

> 这些案例横跨 **网络与协议层、Windows 文件系统并发、Git 跨平台哈希、多 Agent 流水线可观测性、以及复杂前端状态渲染**——共同点是：**不靠重启碰运气，全部追到代码/协议/系统层根因彻底根治。**

## Case 1 · UDP 无握手直采导致的魔数 ID 映射失效（网络与协议层 · 通用模式）
- **现象**：在流式传感器/骨骼数据链路由 TCP 切换至低延迟原始 UDP 模式直测端到端延迟时，客户端无法正常匹配并渲染实体节点数据。
- **根因**：抓包对比 TCP 与 UDP 路径后发现，原始 UDP 直接绕过了 TCP 握手初始化阶段，导致数据包中返回固定十进制魔数 `actorId`，客户端按默认 `0, 1...` 索引匹配全部落空。
- **根治**：在协议接收层将未握手魔数 `actorId` 显式映射归一化为标准连续索引 `0, 1...`，打通无缓冲 UDP 延迟直测链路。

## Case 2 · 826 条单测中 `rewind` 用例 1/12 概率偶发失败（Windows Flaky Test）
- **现象**：多 Agent 引擎全量单测偶发出现约 `1/12` 概率失败，在 `40–95ms` 内快速抛出 `400` 且报错 `chatId` 为空。
- **根因**：回溯调用链发现并非 `rewind` 逻辑缺陷，而是前置 `saveChat` 在 Windows 下执行 `tmp + rename` 原子写覆盖已存在文件时，偶发与系统索引器/杀软文件句柄冲突触发 `EPERM`。
- **根治**：在存储落盘层针对 Windows 原子替换 `EPERM` 做受控退避与写入健壮性加固，彻底消除 Flaky Test。

## Case 3 · 变更账本门禁 60 个文件全量误报 `modified`（跨平台 Git/CI 层）
- **现象**：仅修改 3 个文件，但 preflight 变更账本校验却报告全仓 60 个文件全部变更，导致质量门禁彻底失效。
- **根因**：双层叠加——① 脚本硬编码 `../..` 假设在兄弟仓库布局下解析错根目录；② 本机 `core.autocrlf=true` 使工作区检出 CRLF，而账本基准哈希按 LF 字节计算，导致每个文件 SHA 全不匹配。
- **根治**：修复根目录定位逻辑并将校验哈希改为**先按 LF 归一化再计算 SHA**，彻底消除跨平台换行符误报。

## Case 4 · 多 Agent 流水线降级原因丢失失败节点名（可观测性层）
- **现象**：多 Agent 编排流水线异常降级时，`degradedReason` 永远只打印一句无用的 `"pipeline failed"`，无法定位究竟是哪个角色节点挂了。
- **根因**：虽然外层已有 `[...steps].reverse().find(step => !step.ok)` 归因逻辑，但内置节点（典型如 `critic` 拿不到上游正文）在进入 `runStep` 前即抛错，`steps` 数组根本没记下失败行。
- **根治**：在 `director-pipeline` 调度层循环外包裹 `try/catch`，捕获异常时用明确 `nodeId` 补写 `{role, ok: false, error}` 后再原样抛出，恢复精准节点级故障追踪。

## Case 5 · 宿主隐藏楼层索引偏移 & 1.7 万行前端跨平台串台（前端状态与 DOM 层）
- **现象 A（开源扩展 `chat-autobackup`）**：状态变量卡自动备份的楼层号总是与界面显示错位。  
  **根因与修复**：通读宿主 1.18.0 前端渲染源码（`redisplayChat`）证实 `is_system` 隐藏消息同样参与数组下标赋 `mesid` 占楼号，修正计数口径为最后一条消息真实数组索引。
- **现象 B（大型前端改造）**：多社媒平台共用视图类时，设置页开关点击无效且后台任务相互覆写页面。  
  **根因与修复**：定位到全局同名 DOM ID 被绑定到隐藏图层控件、以及 8 处 `setContent` 硬编码同一 `viewId` + `</textarea>` 未转义击穿 DOM；通过平台作用域隔离、`@scope` CSS 锁定、HTML 转义与 `node --test` 自动化回归（跨双仓共 39 套全绿）彻底根治。
