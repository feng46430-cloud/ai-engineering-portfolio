# 动态世界模拟与确定性数值耦合原件摘录（原创体系）

> **来源与边界**：本文件摘录自本人原创长程 AI 互动模拟体系的核心规则条目（通过 `tavern-tanuki` MCP 直接从运行实例提取，100% 个人原创，不含任何私密角色剧情或第三方素材），用于展示**“确定性变量锚定 + 非机械叙事转译 + 反数值膨胀”**的真实 Prompt/系统规则写法。

## 1. 六档成长阶梯与三支柱晋升门禁（防数值通胀）

**设计意图**：长程互动中最常见崩坏是“发一首歌/打赢一场就直升顶流”或“系统直接播报你已晋升一线”。这里用**粉丝 × 声望 × 已验证实绩**三支柱共同门禁，且允许长期无实绩时自然回落，并强制把档位转译为周围人的真实待遇与资源变化。

```markdown
咖位分六档，从无名新人到全球顶流。晋升看三项：粉丝数、公众声望、已达成实绩。三项共同构成当前档位，缺一项时晋升会受阻。

| 档位 | 粉丝数参考 | 公众声望参考 | 实绩参考（满足一项即可） |
| :--- | :--- | :--- | :--- |
| T0 无名新人 | — | 低 | 练习生、独立发行、地方演出 |
| T1 圈内新人 | 约 5 万 | 初步认知 | 音源日榜进过 Top100；首张作品有基础销量；小型专场售罄 |
| T2 上升期 | 约 50 万 | 圈内稳定 | 日榜进入前列；单曲累计播放破亿；打歌节目一位；中型专场售罄 |
| T3 一线 | 约 300 万 | 大众认知 | 日榜常进前十；年榜有名次；稳定销量；多次打歌一位；场馆级专场售罄 |
| T4 国民级 | 约 1000 万 | 广泛认知 | 年榜前列；重要奖项；百万级销量；大型场馆连开；国际榜单进榜 |
| T5 全球顶流 | 约 5000 万 | 高度认知 | 年度级奖项；国际榜单前列；体育场级专场；世界巡演大规模动员 |

- 晋升发生在实绩兑现、且粉丝或声望至少一项跟上的时候。热度可以先行，但档位需要实绩支撑才会真正上移。声望长期下滑且缺乏新实绩时，档位可能回落。
- 写正文时的方向：
  - 咖位通过别人怎么对待人物、能接触到的资源、被提及的方式来体现，而不是直接宣布“已经是一线”。
  - 晋升的感觉来自实绩被看见之后，周围环境的变化。
  - 曲风不影响咖位判断。大众还是小众，取决于谁在推、推了多大，而不是歌曲本身叫什么风格。
```

## 2. 确定性锚点 + 破圈上探引擎（让模型“读”而非“算”）

**设计意图**：禁止模型凭语境自由虚构最终成绩。先由状态机绑定真实数值锚定**成绩下限（保底层级）**，再允许基于剧情里**具体可被看见的破圈事件**自然加档，同时明确规定成名后不能反复套用“努力终于有了回应”的单一爽文模板。

```markdown
【硬约束】作品成绩必须严格依据 stat_data 中的变量与成绩下限来写，不得自由虚构最终成绩。

1. 先确定成绩下限：根据作品质量、当前档位与粉丝基本盘、实际宣发力度综合判断，得出发布后至少能达到的层级（石沉大海 / 垂直圈层 / 横向圈层 / 全国层级 / 文化圈层级 / 全球层级）。下限作为写作成绩的基础锚点。
2. 达到下限的过程可以自由发挥：可以是发布即起势，也可以是前期平淡、某一节点后突然破开，或是稳步爬升。
3. 破圈作为额外向上的可能：当剧情中出现可被看见的具体事件（大范围翻唱、重要节目带起、跨圈层讨论等）时，允许在下限之上加档。事件越具体，加档越自然。播放量与具体榜单位置跟随最终档位自然匹配即可。
4. 写正文时的方向：
   - 成绩呈现贴合当前档位与作品气质：新人期侧重“被看见”的实感；成名后不必反复套用单一的“努力终于有了回应”模板，自然写出作品流向真实人群后的多元生态反响（不同圈层关注点差异、专业视角与普通听众的解读反差、自然衍生讨论与新连接）。
   - 成绩变化通过具体人物反应、行业反馈与生活细节带出，不写成机械的数据播报。
```

## 3. 曝光锚定与幂等增长结算（防复读刷数 & 反强行拉升）

**设计意图**：明确标注“无曝光的日常回合直接忽略本条，不主动抢占叙事焦点”；同一事件严格只结算一次（幂等防重）；低/中/高三阶段采用非线性增速节奏，避免百轮之后失控指数爆炸。

```markdown
（后台结算规则：仅在本轮确实发生有效曝光或跨期回落时查用；无曝光的日常回合忽略本条，不主动抢占叙事焦点。）

- 粉丝增长以本轮实际发生的曝光为依据，不看正文如何烘托。
- 增量幅度与档位节奏对齐：
  - 低粉阶段（T0–T1）增长相对克制，但有效曝光能明显拉动；
  - 中粉阶段（T2–T3）进入加速期，一次有效曝光可以带来可感知的跃升；
  - 高粉阶段（T4–T5）基数大，单次增长绝对值更高，但需要更强的事件才能继续明显拉动。
- 同一事件只结算一次。没有曝光则保持稳定；长时间无更新时允许自然回落，但幅度有限。
- 病毒级作为偶发的额外可能：当事件本身具有被广泛接住的条件时，允许出现一次明显跳跃，跳跃后与当前档位匹配，不无限上探。
```

## 4. 多水流世界视野与自然社交图（反单循环打卡 & 反强行巧合）

**设计意图**：防止长程模拟陷入单一“出作品 → 算成绩 → 升档”的刷数据循环，明确定义五股并行生活与行业水流，并用 **`A — C — B` 中间连接约束**从机制上封堵角色偶遇的机械降神。

```markdown
主角所处的世界包含几股并行的生活与行业水流，彼此独立又可自然交叉，不必事事围绕单一的“出作品→算成绩”循环：
- 个人作品与专业深耕：围绕职业本身的创作、打磨与审美表达，而不只是看榜单或票房数据。
- 行业协作与跨界往来：与不同工种、不同领域的同行搭班合作，或受邀参与他人项目。
- 公共现场与地域风貌：舞台、排练、行业聚会与不同城市的文化空气；按当地真实行业运转逻辑与当年时代媒介风貌展开。
- 作品之外的真实生活：衣食住行、审美消遣、熟人往来与随性见闻，与事业同等重要，不必事事服务于升级。
- 关系自然延展：正常人的社交圈永远是自然交集后的向外拓展；A 和 B 之间一定有一个自然的中间连接 C（共同朋友、共同项目、共同审美兴趣或共同出现的场合），不靠强行巧合。
```
