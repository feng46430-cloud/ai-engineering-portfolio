## 一、第一原则：为什么必须把“算数和判输赢”拿离大模型？

大模型本质是概率文本生成器，存在两个与游戏玩法天生冲突的底层属性：① **迎合偏置（Sycophancy）**——玩家一句话就能“嘴炮秒杀强敌”或把失误美化成高光；② **算术与长程守恒失能**——多变量数值跑几十轮必然通胀、死锁或自相矛盾。

**解法 Spec**：严格切分「确定性规则引擎层」与「大语言模型演绎层」——**所有随机性、实力差阈值、成长门禁与幂等结算全部外置计算并固化为只读状态，模型只负责读取客观裁定结果，将其演绎为有血有肉的剧情与人物博弈。**

```mermaid
flowchart LR
    U["玩家自由输入"] --> E["外置确定性裁定层<br/>实力差/真随机/红线锁/三支柱门禁"]
    E -->|"只读客观 Verdict<br/>(严禁模型改写输赢)"| LLM["大模型叙事演绎层<br/>视角隔离 + 因果演出 + 细节转译"]
    LLM --> V["后置确定性校验<br/>正则防骰值篡改 + 嵌套变量自愈"]
    V --> S["状态机 7 步确定性落盘"]
```

## 二、四大核心系统 Spec 架构

### 1. 长程反通胀架构：六档阶梯 × 三支柱晋升门禁
- **根因问题**：单一粉丝数或战力分门槛极易导致“一夜封神”或社媒型/巡演型错位（13 位真实中外艺人对标中发现 4,000 万区间存在显著层级重叠，证明单维阈值必然失真）。
- **Spec 契约**：
  - 晋升必须同时满足 **`基础盘（规模） × 公众声望 × 已兑现实绩`** 三支柱门禁，缺任一维度均硬锁在当前档位；
  - 支持长期无实绩时的受控自然回落（配套离线 3 档衰减敏感度仿真锁定 3 轮回落上限，防止趋近归零）；
  - **去播报化转译**：禁止系统播报“你已升至某档”，档位变化必须通过周边 NPC 态度、可接触资源门槛与行业称谓自然显化。

### 2. 确定性下限 × 破圈上探引擎（幂等防刷）
- **Spec 契约**：
  1. **只读下限锚点**：先由外置状态机基于作品质量、当前档位与宣发投入锁定保底层级（`6` 档离散区间），模型严禁凭空虚构超越基本盘的成绩；
  2. **事件驱动上探**：仅当剧情中出现真实可感知的跨圈层破圈事件时允许按档上浮；
  3. **单轮幂等结算**：同一事件严格只结算一次；无曝光日常回合零触发结算，彻底避免“日常闲聊也在刷数”；
  4. **7 步确定性单轮结算序**：消除同轮多规则读写竞态，确保档位判定永远位于全部状态更新之后。

### 3. 防“嘴炮无敌”硬阈值裁定 Spec（动作/竞技通用范式）
- **战斗模拟（五档实力差硬阈值 +「设定＞代码」）**：
  - 外置裁定引擎综合当前多维实力值（`ASV`）、敌方威胁等级（`TL 1–10`）、伤疲衰减与加密真随机（`crypto.getRandomValues`）输出五档客观裁定；
  - **碾压劣势红线（`delta <= -32`）**：明文锁死**禁止嘴炮或强行爆种翻盘**，正面硬拼必遭重创或溃败，倒逼玩家转向情报侦察、地形/兵器弱点克制、队友协同或高代价等价交换；
  - **规则层级**：已成立的世界观铁律与等价束缚优先级高于通用数值公式（「设定＞代码」），防止死板公式扼杀高光策略创新。
- **竞技模拟（模块化规则 `94.5%` 常驻瘦身 + 四档真骰防美化）**：
  - 在体育生涯模拟（《足球人生》重构版）中，将旧版约 `40,136` 字常驻设定重构为 **24 条模块化规则（仅 6 条常驻共 `2,193` 字、17 条按赛事/转会场景激活、1 条仅首轮初始化触发，常驻字数压降 `94.5%`）**；
  - 按六维属性、实时体能、惯用脚/逆足与伤病结合 `d100` 真骰划分 4 档赛场硬裁定，在低档结果中**明文禁止模型将失误强行美化为进球/得分**，配套动态记分牌 HUD、转会窗四方博弈与更衣室生态。
- **游戏内持久化 AI-UGC 创作闭环（演艺模拟词曲管理器）**：
  - 在《星光旅途》内置游戏内词曲创作管理器：支持玩家输入轻量灵感与曲式骨架，后台调用静默生成接口扩写完整曲目档案，自动挂载检索分类标签持久化写入世界知识库，并与后续打歌宣发及商业榜单结算实时联动。

### 4. 活世界生态、动态 NPC 转正与三阶事件记忆 Spec
- **属性 → 行为表现梯度锚定（Attribute-to-Behavior Grounding）**：将 7 项 0–100 抽象成长数值系统拆解为 5 档具体可执行的行业行为表现锚点（动作、节奏、临场反应），避免只喂模型裸数字导致表现断层。
- **路人 NPC 自动转正持久化（Dynamic NPC Promotion）**：当交互中涌现出高戏份路人/新角色时，自动抽取结构化档案（`MBTI + 荣格八维底色 / 能力边界 / 阵营背景`），经去重防重名校验后编纂写入长期知识库，保证动态角色跨百轮性格与记忆不漂移。
- **活世界防通胀与后台演化**：
  - **6 档关系/好感防通胀标尺**：默认不动，仅当实质剧情事件打破当前阶段时才克制变动，杜绝廉价“聊两句好感 +5”；
  - **动态生态蓄能/泄压水位（`eco_pressure`）**：按“微澜 → 板块联动 → 篇章大事件 → 自动泄压回落”调度世界张力，避免全服持续高压或死水；
  - **时间跳切蒙太奇结算**：玩家跨周/跨月跳过时自动结算离线期间其他 NPC 独立办完的事务，打破“玩家不动全宇宙冻结”；
  - **事件三阶记忆压缩 + 4 态人机协同自愈（Human-in-the-Loop）**：`活跃事件（1–3 条）→ 永久蝴蝶锚点 → 超阈值无损合并为高密度里程碑`；长线议程设 4 态（待展开 / 进行中 / 已完成 / 已失效），默认由 AI 在节点落地时自动划勾，偶发漏改时玩家可直接在前端 HUD 点击复选框 **1 键手动修正状态机并同步下轮宏**；配套核心运行时**本地优先加载 + 双 CDN 三级容灾回退**与常态↔爆发双形态实时折算（含三道自动唤醒安全锁，退出零存档污染）。
- **多水流世界视野与 `A — C — B` 社交图约束**：并行定义「专业创作 / 行业协作 / 公共现场 / 私人生活」多股独立水流；新角色/新事件引入须满足 `A — C — B` 桥接连通条件，封堵机械降神。
- **混合算力路由（N→1 群体教练 + Spotlight 独立隔离）**：常规回合用 1 次群体教练统筹全部在场 NPC 控算力，仅在高张力摊牌/信息差对决节点为 1–2 名核心 NPC 拉起私有视野子 Agent，配套 Flash 快模型定向提示词瘦身以适配商业低延迟场景。
- **非对话类独立概率系统 Spec（防摸包洗牌 + 期望守恒）**：另独立完成集换卡拆盒模拟系统 Spec（五层商品建模、整盒保底 + Fisher-Yates 防摸包洗牌 + 基础掉率补偿守恒消除保底通胀 + 全局唯一 `1/1` 库存耗尽锁 + `mulberry32` 种子复现），验证通用商业游戏数值与概率建模能力。

## 三、代表性规则切片原件与设计解析（Sample Slice）

以下节选 1 条原创演艺模拟中「确定性锚点 × 事件驱动上探」的核心切片（完整六档阈值系数表、战斗裁定全量脚本与多水流触发权重保留于私有环境）：

```text
【硬约束】作品成绩必须严格依据 stat_data 中的变量与成绩下限来写，不得自由虚构最终成绩。
1. 先定下限锚点：依据作品质量、当前档位基本盘与实际宣发力度锁定保底层级，作为叙事基础锚点；
2. 过程允许弹性，上探必须有据：仅当剧情中出现真实可被看见的具体破圈事件（大范围二创、重要舞台、跨圈层争论）时允许在下限之上加档；
3. 反单一逆袭模板：成名后严禁反复套用“努力终于有了回应”的单一爽文句式，应呈现不同圈层关注点差异、专业视角与大众解读的反差及自然衍生的新连接。
```

- **为什么这么设计？** 如果只锁死数值，故事就会退化成冰冷的 Excel 播报；如果不锁下限，大模型就会因为迎合偏置把新人首单写成全网封神。这套切片把**“下限确定性（代码锁死）”**与**“过程/上探自由度（剧情事件触发）”**一分为二，再用第 3 条直接切掉高档位最常见的“永远在写逆袭打脸”的疲劳模板。
